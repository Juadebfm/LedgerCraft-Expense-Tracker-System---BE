# Glossary

| Term | Meaning |
| --- | --- |
| API | A contract through which one program requests work from another. |
| Authentication | Proving who a caller is. |
| Authorization | Deciding what an authenticated caller may do. |
| Bearer token | A secret token sent in an `Authorization` header. |
| CI | Automated checks run for source-code changes. |
| CORS | A browser rule limiting which origins may call an API. It is not authentication. |
| Docker | A tool for running isolated local services in containers. |
| Environment variable | Configuration supplied outside source code, such as `PORT`. |
| Fastify | The HTTP framework LedgerCraft will use to register routes. |
| Foreign key | A database rule requiring a value to refer to an existing row. |
| HTTP status code | Numeric request result, for example `200`, `401`, or `403`. |
| JWT | A signed token format commonly used by authentication systems. |
| Migration | A version-controlled SQL change. |
| Modular monolith | One deployed application organised into focused modules. |
| PostgreSQL | The relational database used through Supabase. |
| RLS | Row Level Security: PostgreSQL policies that restrict rows by caller. |
| Route | Code for one HTTP method and path. |
| Supabase | Hosted/local services providing Auth, PostgreSQL, and Storage. |
| Test | Executable proof of expected behaviour. |
| Transaction | A group of database operations that succeed or fail together. |
| Zod | Runtime validation library used for configuration and future request input. |
